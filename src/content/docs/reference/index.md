The complete API of both gems, for the released versions this site is checked
against: **field_struct v0.15.0** and **actionable-rb v1.9.0**. Every runnable
example on these pages is executed in CI against exactly those releases.

Pages are grouped by gem in the sidebar:

- **field_struct**: declaring fields, the types and their options, dates and
  times, validation and errors, class macros, the instance API, JSON,
  registries and custom types, introspection and tooling, exceptions.
- **actionable**: actions and steps, control-flow verbs, results, input and
  output, declared outcomes, hooks and history, batches and introspection, the
  optional adapters (jobs, Rails, testing, RuboCop), RBS and exceptions.

New to the gems? Start with the [tutorial](../tutorial/bookstore-checkout/).
Wondering *why* something works the way it does? See
[Explanation](../explanation/).
